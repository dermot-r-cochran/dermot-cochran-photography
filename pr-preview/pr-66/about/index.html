About

Dermot R. Cochran is a Senior Machine Learning Engineer based in Dublin, Ireland, with a long-standing interest in macro, wildlife, landscape, architecture, and nature photography. He is a member of Dublin Camera Club.

Outside of photography and engineering, he writes Star Rangers, an interactive science-fantasy serial, at sciencefiction.site.

How this site is built

This site is a static site built with Eleventy. Content lives as Markdown and Nunjucks templates in this repository's src/ directory; npm run build compiles it to the static _site/ output, and npm run start serves it locally with live reload.
